# CODEX<>PRO

منصة Android-ready لإنشاء مستندات متعددة المحتويات، باستخدام محرر كتل (Block Editor).

## أنواع المحتوى
- نصوص وشروحات.
- أكواد برمجية مع زر نسخ مستقل لكل كتلة.
- صور.
- روابط خارجية.
- جداول وقوائم.
- مرفقات وملفات.
- فيديوهات YouTube وVimeo.

## الموجود في هذه النسخة
- واجهة Cyberpunk بنفسجي / سماوي / أسود.
- مكتبة مستندات وبحث وتصنيفات.
- قارئ مستند يعرض الكتل بالترتيب.
- محرر للإدارة يضيف الكتل ويحذفها ويعيد ترتيبها.
- حفظ ونشر ومسودات محلياً في المتصفح.
- نسخ الأكواد.
- شاشة تحديثات تجريبية.
- تبديل أدوار للمعاينة (مالك / مدير / مستخدم).
- مخطط Supabase أولي مع RLS وإنشاء دور user تلقائياً عند التسجيل.

## تنبيه بخصوص النسخة الحالية
هذه **نسخة واجهة وتجربة محلية**. لم يتم بعد تنفيذ تسجيل دخول حقيقي أو ربط التطبيق فعلياً بقاعدة بيانات Supabase. البيانات تحفظ في Local Storage على نفس الجهاز والمتصفح. تبديل الدور في صفحة الحساب للمعاينة فقط وليس حماية أمنية. لا تضع بيانات خاصة أو ملفات مهمة في هذه النسخة التجريبية.

## التشغيل على الكمبيوتر
1. ثبّت Node.js 20 أو أحدث.
2. افتح مجلد المشروع في الطرفية.
3. نفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. افتح عنوان Vite المحلي الذي يظهر في الطرفية.

## تجهيز Android APK
يتطلب بناء APK وجود Android SDK / Android Studio:
```bash
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```
ثم من Android Studio اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

يوجد GitHub Actions workflow داخل `.github/workflows/build-android.yml` لبناء Debug APK عند تشغيله يدوياً أو عند الدفع إلى الفرع `main`. بعد نجاح المهمة نزّل Artifact باسم `CODEX-PRO-debug-apk`.

## رفعه إلى GitHub
ارفع محتويات هذا المجلد إلى جذر المستودع، وليس المجلد الخارجي نفسه. يجب أن يكون `package.json` و`index.html` في جذر المستودع.

## ربط Supabase في المرحلة التالية
1. أنشئ مشروع Supabase.
2. افتح SQL Editor ونفّذ `supabase/schema.sql`.
3. ضع Project URL و anon/publishable key في `src/config.js`.
4. فعّل مزود Email في Authentication واترك التسجيل مفتوحاً إذا كان هذا المطلوب.
5. أنشئ حساب المالك، ثم غيّر role إلى owner باستعلام bootstrap المعلق في نهاية ملف SQL.
6. يلزم بعد ذلك استكمال كود المصادقة، وجلب المستندات وحفظها سحابياً، ورفع المرفقات، وإجراءات الحظر والترقية، قبل اعتبار التطبيق جاهزاً للإنتاج.

**ممنوع:** لا تضع مفتاح `service_role` داخل JavaScript أو مستودع GitHub أو APK.
